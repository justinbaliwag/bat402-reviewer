Model Selection Decision Matrix

Always ask: "What is the data type of the outcome variable?"[cite: 1]

Regression

Outcome is a Continuous or Count Number (e.g., revenue, selling price, delivery minutes, electricity bill)[cite: 1, 2, 10].

Classification

Outcome is a Category / Binary Group (e.g., default vs no default, spam vs ham, renew vs cancel)[cite: 1, 2, 11].

Time Series

Outcome is Numeric and strictly ordered over regular time intervals (e.g., daily orders, monthly ridership)[cite: 1, 6, 13].

Regression Syntax & RMSE Logic

Study Tip: Read RMSE from the inside-out: errors → square (errors^2) → average (mean()) → root (sqrt()) to get back to original units[cite: 3].

4

Decision Tree & Confusion Matrix

Mandatory step: df$approved <- as.factor(df$approved) prior to fitting![cite: 2, 4]

R Matrix Indices Actual 0 Actual 1
Predicted 0 TN [1,1] True Negative Pred 0, Act 0 (Correct) FN [1,2] False Negative Pred 0, Act 1 (Missed!)
Predicted 1 FP [2,1] False Positive Pred 1, Act 0 (False Alarm) TP [2,2] True Positive Pred 1, Act 1 (Correct)
How to Remember the Terms:
TN: Predicted 0, Actual 0 (Correct)[cite: 5]
FN: Predicted 0, Actual 1 (Missed positive)[cite: 5]
FP: Predicted 1, Actual 0 (False alarm)[cite: 5]
TP: Predicted 1, Actual 1 (Correct)[cite: 5]
Accuracy: (TP + TN) / Total
Precision: TP / (TP + FP)
Recall: TP / (TP + FN)
5

When to Prioritize Recall vs. Precision

Prioritize RECALL when:

Missing a true case (False Negative) is catastrophic or costlier.
Examples: Catching cancer, student failing/dropouts, loan defaults, fraud[cite: 5].

Prioritize PRECISION when:

A false alarm (False Positive) wastes expensive resources or annoys users.
Examples: Spam filter deleting real email, expensive remediation invitations[cite: 5].

6

Time Series & Moving Average Window

Frequency Rules: Daily with weekly pattern = 7. Monthly with yearly pattern = 12[cite: 6, 7].

Decomposition 4 panels: Observed ($x$), Trend, Seasonal, Random/Residual[cite: 6].
